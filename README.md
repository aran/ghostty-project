# ghostty-project

Ensure a Ghostty tab running Claude Code for each folder in a project.

```sh
curl -fsSL https://raw.githubusercontent.com/aran/ghostty-project/main/ghostty-project -o ~/.local/bin/ghostty-project
chmod +x ~/.local/bin/ghostty-project
```

List one folder name per line in `~/.config/ghostty-projects/<project>`, then run `ghostty-project <project>`.
